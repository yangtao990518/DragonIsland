# mAIverse V1.8 build 19

- 修复用户和 AI 都无法发送内置表情的真机问题。读取可以从安装包回退，写入和文件属性更新永远只进入用户可写 Media 目录；实际发送的表情会保留快照并进入备份。新增只读安装包场景下的用户发送、AI 工具发送和备份恢复端到端回归。
- 聊天输入栏改为紧凑圆角布局：左侧加号展开相册／文件，表情入口常驻，右侧固定尺寸发送按钮；待发附件提供缩略图与移除按钮。表情选择改为角色标签与网格，可直接开启该角色 AI 表情权限；点选后加入待发区，再点发送。
- 角色详情正式落地月光档案原生界面：奶白／淡紫／金色细边、大立绘、左右展示图切换、横向缩略图名称与选中标记，以及展示／日常／设定入口。两位角色共用布局，旧的两张大立绘／小人物卡片移除；大图查看仍可用。不是一张整页图片。
- 日常动作页改为月光风预览舞台与动作卡片；当前动作标签在两位角色相同位置。App 预览与灵动岛自动活动开关独立。没有重新生成动作素材或改变已确认排程。
- 主动聊天设置移到「角色 → 对应角色档案 → 主动聊天」，聊天页旧入口移除。每位角色独立设置开关、允许时段、最短联系间隔、私聊／指定群聊 @、系统通知和灵动岛提醒。
- 用户明确选择：**只设置两条主动消息的最短间隔，实际时间继续随机**。默认 10:00–18:00、最短 60 分钟；可按 15 分钟步进在 15–480 分钟设置。不是每小时整点联系，也不保证固定周期；不越过允许时段，不集中补发。
- 修改一位角色不会取消另一位的待发安排。升级保持旧版设置和已准备消息；保存该角色页面后才采用新的独立时段与间隔。随机时点先持久化，重复打开不重新抽样或反复调用计费接口。
- 仍为手机本地预生成方案：App 有运行机会才准备新消息，已准备的系统通知可以锁屏投递；最多提前保留 32 条待发安排，两位角色按时间共享队列。不能保证长期后台持续生成或到点更新灵动岛；没有接入服务器／APNs。
- AI 人格编辑页本身按用户要求保持原版。聊天记录、Keychain、正式主页动画、遛狗 96 帧／1.6 秒、御剑／骑鲸和两段完整舞蹈保持原数据与方案。

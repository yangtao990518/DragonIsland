# build23 游戏体验改造

以本记录优先于build22的“244项全部可作为攻击”方案。用户真机反馈：竖屏、人物难辨认、地图简陋、多技能卡顿、英文技能、非攻击素材混入、伤害与画面不符、升级无图标和数值、无音乐音效。

- 游戏单独横屏，退出恢复App竖屏。使用系统窗口方向请求和AppDelegate方向掩码，项目声明允许横屏。
- 人物显示高度100，脚下青色定位环，角色在战斗效果上方，受击最低透明度提高。人物原画和原动画不重绘。
- 原方格地图改为静态月夜庭园地面：弯曲小径、浅水池、荷叶、石缘、草花灌木。场景装饰为地面画面，不阻挡移动。
- 244项素材全部中文命名并保留预览。严格区分攻击、辅助、物品、展示。首批校准18攻击＋2治疗参与战斗与升级，其余默认隐藏，可开启查看，不能装备；不把物品、天气、转场伪装成攻击。后续逐个做实际机制再扩充。
- 校准数据在 `Art/PixelFXMasters/gameplay.json`，每技能指定命中半径和生效延迟。投射物去掉原先22点的视觉抬高，和判定使用相同地面位置；范围技能在落点显示实际伤害圆及预警期，延迟后才伤害，治疗仅回复生命。仍为圆/扫掠圆判定，不宣称逐像素或已完成所有特效的独立机制。
- 升级横向三卡有实际缩略图、当前/下级具体伤害、半径、冷却、弹数、穿透。详情可看1—5级数值。
- 战斗读取专用小图集：主角长边192、怪物/特效96，每页不超过768；保留每一帧及全部原时间戳、全长、不加速，原完整清晰图集继续供素材库预览。背景线程解码，战斗前和技能变更后预载到GPU；战斗帧不再同步读盘。图集和技能查询改字典，反馈数量10上限，施法实例16上限。
- 内置原创程序合成的32秒循环背景音乐及施法/命中/治疗/升级音效，驻留小音频池并限频混音；暂停/后台停止播放，音乐与音效独立保存开关。不是商业录制音轨。
- 继续旧局时更新技能分类，保留时间/血量/经验/被动与合法已学技能；撤下不能再装备的旧展示特效，补充合法初始技能。聊天、记忆不改。

验证状态：准备运行新逻辑、资源和实际横屏模拟器测试，包括6满级技能＋100怪物的界面压力场景。真机整局20分钟、发热、耗电和帧率仍需实际设备验证，不能沿用build22结果或宣称已消除全部卡顿。

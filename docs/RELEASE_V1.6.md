# mAIverse V1.6 改动清单

内部 1.6 / build 12。本机交付目录为 `D:\gpt_workspace\ios_ldd\mAIverse-V1.6\`，旧版目录保留。

- “关于”新增“岛上小世界”，可选经典黑色、小小草地、月下星夜。选择会保存，切换时应用到当前陪伴，不重置倒计时或动作时钟。
- 场景进入紧凑态人物活动区、倒计时内容区、展开内容和锁屏卡片；App 内首页、角色详情及任务预览同步显示。系统灵动岛黑色外壳与摄像头区域保留，不声称能替换整个系统背景。依据：[Apple — Creating custom views for Live Activities](https://developer.apple.com/documentation/activitykit/creating-custom-views-for-live-activities)。
- 纠正 V1.5 对“速度慢”的理解：重点扩大行程，不再加快迈腿。人物活动区从 32×32pt 增为 60×32pt，人物尺寸保持；原横移约 8pt，本版在可见内容区走约 33.3pt，安全留出角、翅膀、尾巴与边缘间距。
- 单程移动约 4.5 秒，前后各约 0.25 秒转向 / 收脚；选中走路后安排相邻两段，先去另一端、再折返，不等下一次随机才回来。两段合计约 10 秒，其后再选择待机、走路或打滚。
- 左右步态每循环约 1.125 秒，较 V1.5 的 0.533 秒明显放慢；保留 30fps 系统计时采样，让位移仍平滑。打滚从短时间连续两次改为约一秒轻滚一次，再回到待机。没有把增加采样率当作加速动作。
- 三种场景的帧均预合成为完整不透明画面，继续覆盖旧姿势，保留 V1.5 的提前准备字形时序。每种场景使用固定颜色表，避免按帧量化使草地 / 天空闪色。场景图形由项目脚本绘制，不修改已确认的白紫角色和大立绘。
- 切换场景时更换整组计时视图身份并关闭人物交叉淡化，避免紧凑态滞留旧字体场景；系统提交有延迟，实际验证等待画面显示所选场景，再继续检查。
- 展开态和锁屏使用独立 900×300 场景资源，月亮、星点和草地重新按大画布绘制，避免放大紧凑态缩略图造成明显像素边缘。
- 最小态和展开名称旁小图保持静态；关闭自动活动、减弱动态或息屏低亮度仍使用静态人物。原有人物卡片、看图手势、深浅 App 外观、五款图标与互动按钮保留。
- 验证增加场景保存 / 旧会话兼容、三种场景防重影、全身端点不裁切、去程与返程完整到边；云端还检查实际系统场景切换、持续显示、六段屏幕横移范围和跳帧。实际通过结果与包校验值以 `VALIDATION.md` 最终交付记录为准。

30fps 是播放目标；系统可能降帧。本轮没有操作用户手机、签名或测量 iOS 27.01 真机帧率。自动动作仍为预排 60 秒循环，未新增后台逐帧更新、服务器、AI 对话或响铃。

Sideloadly 必须保留并签名 `PlugIns/DragonIslandWidget.appex`。升级后结束旧活动，再开始新一轮，按 `TEST_GUIDE.md` 验证。

# mAIverse V1.8 build 20

- 角色展示图缩略图改为完整等比显示，不再只露人物的一部分；去掉重复的展示／日常／设定栏，保留下方实际功能入口与各角色已保存选择。
- 聊天列表未读数改为头像右上角红底白字角标，移除会话右侧的孤立数字。点击聊天内容或空白区域收起键盘，未发送草稿仍保留。
- 聊天灵动岛改为正常版角色头像＋右侧红色未读数，展开与锁屏卡片也使用头像。头像沿用系统计时字体帧方法轻微左右晃动；仅平移既有头部图片，不生成表情或姿势。减弱动态／低亮度时使用静态头像，未修改陪伴动作计划或正式动画。
- 关于新增「AI 记忆与本机文件」。角色记忆文件夹、每条文件实际大小、编辑、删除、新建、清空入口均可用；现有 history.json 和媒体占用另列，聊天上下文可以按会话编辑或删除，避免直接破坏内部 JSON 与附件关联。
- 本包首次实现独立长期记忆：手机本地 Application Support/Chat/Memory/<角色ID>/<UUID>.md。小白与大肥鱼物理分目录，后续聊天与主动开场只读取自己的已保存文件；默认最近10轮上下文仍按角色原配置。
- 同时支持手动记忆和 AI 自动整理候选。每个角色单独开启自动整理，默认关闭；开启后每5轮已完成新文字对话整理一次，每次最多取最近12条、24000字用户原话。开启时不自动上传整个旧档案；可在文件夹菜单主动整理已有聊天。
- AI 整理使用该角色原有模型与密钥，会消耗接口额度，但不调用 App 操作或表情工具，不伪造聊天消息。最多产生5条待确认候选，必须有真实用户消息ID与逐字出处；用户可修改、保存或丢弃，确认前不会成为 AI 长期记忆。失败、中断不自动重复扣费，可手动重试。
- 记忆编辑影响后续请求；相关角色尚未发送的主动消息会取消并按新内容准备，另一位角色不受影响。无改动保存不重新准备。删除记忆不删除旧聊天，清空聊天也不删除已保存记忆，两个入口分别管理。
- 聊天备份升级为兼容旧版的v3，包含独立记忆及待确认状态。恢复v3使用暂存与目录回滚，失败时保留旧记忆；恢复v1/v2不会默默抹掉已有独立记忆。密钥仍只在Keychain，本页不展示或打包密钥。

沿用原 App／Widget 标识。没有启动模拟器或连接真机验收，没有接通服务器／APNs。后台限制不变：App 有运行机会才准备新消息或记忆候选，系统可以投递已准备通知，不能保证全天候后台生成和后台到点刷新灵动岛。

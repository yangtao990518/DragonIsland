# mAIverse V1.8 — 角色语音闹钟

- 新增「闹钟」页，按角色设置一次性倒计时（1–1440 分钟）或下一次指定时刻。
- 角色详情可直接打开定时；陪伴倒计时可开启到点语音，并按角色保存默认选择。
- 小白加入用户提供的 10 条语音，可试听；保留 MP3 原件，运行资源为短时单声道 PCM WAV。
- iOS 26 及以上使用 AlarmKit 固定时刻系统闹钟，首次请求用户授权。不给已有角色陪伴增加第二个倒计时活动。
- iOS 17–18 使用本地通知声音提醒，受静音、专注模式与通知声音权限影响，不承诺持续响铃。
- 支持查看、修改、取消独立闹钟和重开恢复；系统停止后同步移除记录。
- 结束本轮陪伴（包括灵动岛结束按钮）会取消其关联提醒；独立闹钟不受影响。
- 保留 V1.7 步态、左右移动打滚、三种场景、角色画廊、主题及图标。

本版候选的本地检查：20 项 Python 测试、Swift 语法树检查和 YAML 解析通过。
云端 Xcode 编译、Swift 类型检查、真实系统闹钟触发及模拟器交互正在验证。
模拟器无法证明真机扬声器音量、静音/专注模式表现、音频实际听感或长期稳定性。
签名安装需保留并签名主 App 与 `PlugIns/DragonIslandWidget.appex`。升级后结束旧陪伴，再开启新一轮。

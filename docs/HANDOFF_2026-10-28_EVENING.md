## 去绿幕：最终通过的是 v4

完整历史见 `docs/AI_VIDEO_WALK_REVIEW_2026-10-28.md`。v1 留绿边；v2 只压绿色通道仍有青色描边；v3 收缩/替换轮廓后产生波浪和抖动，已被用户否决。不能以“绿色占优像素为零”宣布观感修好，也不能继续靠侵蚀轮廓解决。

最终用 `Scripts/matte_ai_walk_video.py` 回到原 MP4，分别求透明度和前景颜色：

1. OpenCV 读取原 RGB。HSV 辅助判断绿幕；连通域过滤小压缩噪点，面积阈值 64 像素。腐蚀/膨胀的 7×7 核只用来产生可信前景、可信背景和未知边缘组成的 trimap，**不是最终轮廓**。
2. 发丝狭缝里的绿幕也需要背景锚点，不能只看外部背景。对当前没有绿色服饰的角色，加入高置信绿色色相锚点；同时保护高置信深蓝细发丝、呆毛，避免细线因没有足够内部种子而消失。阈值属于当前角色的配色判断，不能直接套给有绿色衣服的新角色。
3. PyMatting `estimate_alpha_cf` 求 closed-form alpha；拉普拉斯 epsilon 为 `1e-6`，共轭梯度最多 2000 次，`rtol=1e-5`。读源帧 48～145 作上下文，最终交付中间的 49～144。
4. 为防边缘逐帧跳动，用相邻帧的 Farneback 光流将**相邻透明遮罩**对齐到当前帧，再按原 RGB 的一致性轻量加权，权重上限 0.22。只稳定 alpha 的不确定边缘带，可信内部和背景保持原值。光流不生成图像、中间帧、腿或动作。
5. 用 `estimate_foreground_ml` 在已求 alpha 的条件下恢复前景颜色，`n_small_iterations=10`、`n_big_iterations=4`，去掉混进半透明边缘的绿幕颜色。透明度低于 .002 清零，高于 .998 固定为 1；全透明 RGB 清零。不是用邻居颜色粗暴涂边，也没有再次削瘦最终轮廓。
6. 输出直通 RGBA PNG；固定裁剪、原帧序和时序。缓存版本为 `trimap-v4`，旧缓存不能冒充这一版。

检查方法：黑/白/深蓝灰/中灰四背景、发丝/呆毛/鞋袜/绳子/狗耳与脚的放大近景、连续原速视频、循环接缝、全部 96 帧裁剪外透明度、绳子连通性、成片整段回解，以及处理前后原视频哈希。不能只看一张静图或一个色彩统计。

用户最终明确回复“这个可以 没问题”，v4 才获观感确认。源视频本身若有脚掌重叠、形体变化或接缝，提帧与抠像不保证消除；不能宣称达到人工逐帧重绘的效果。

参考项目是 `yshuang722-spec/xiaoxiao-zhuochong`。当时阅读的上游说明记载部分成品用 PR 人工抠像，自动 HSV 只是备选；不能断言其所有后来动作都使用 PR。本机流程使用 Python/OpenCV/PyMatting/FFmpeg，**不依赖剪映或 Premiere**。

## 换机器怎样接着做

只开发/构建当前 App：直接拉取 Git 即可，正式素材已在 `Art/DailyMotions/`，不用恢复旧 ZIP，也不用重新抠像、安装剪映或找回 `output/`。

要从原视频重新抠像：原 MP4 在仓库外，需自行带回；办公室的 `output/ai-video-dafeiyu-walk-v4/` 和工具依赖也不在 Git 中。准备 Python、Pillow、NumPy、SciPy、OpenCV、PyMatting，编码预览时再准备 FFmpeg/libx264。记录中的本机抠像依赖版本为 PyMatting 1.1.16、NumPy 2.5.4、SciPy 1.18.1、Numba 0.68.1、llvmlite 0.50.0、Pillow 13.0.0；按家中 Python/系统安装匹配构建，不复制不兼容的二进制依赖目录。线程曾设 `NUMBA_NUM_THREADS=4`、`OPENBLAS_NUM_THREADS=4`。

`matte_ai_walk_video.py <分析目录> <输出目录>` 从分析目录的 `extraction-analysis.json` 读取 `source`、`source_sha256`、`uniform_crop_xyxy`。可由原解码分析脚本生成该文件，也可按上述已核对值准备；保留 UTF-8 无 BOM。完整重算耗时、缓存较大，应写入忽略的 `output/`，不要自动提交。脚本里的帧范围、光流缩放及放大检查区域当前针对该 1280×720 视频；处理新视频前必须重新适配。

`Scripts/preview_matted_ai_walk.py` 是历史审阅打包脚本，第二参数依赖旧 v3 对照原帧；旧稿已清理，**不要假定刚拉下 Git 就能直接运行这项旧对照导出**。核心 v4 抠像不依赖 v3。要新导出，直接从 v4 的 `frames-source-rgba/0049.png`～`0144.png` 固定裁剪生成 96 张循环帧；不同背景合成仅用于预览，透明 PNG/图集才是透明素材。旧记录里“pending review / app_integrated=false”是当时状态，现已由用户确认及正式集成覆盖。

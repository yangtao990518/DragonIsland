# AI语音消息与独立角色音色：完整实施方案

状态：设计方案，尚未接入真实TTS、创建云端音色、上传录音或生成新IPA。现有闹钟的固定音频不等同于聊天语音功能。用户已选回淡紫卡片版聊天设置UI，小白、大肥鱼必须共用页面结构、间距与控件顺序，配置和数据按角色隔离。

## 目标与整体流程

沿用现有DeepSeek角色模型、人设和记忆上下文生成回复；用独立TTS服务合成音频，在聊天中发送真实语音条。保留对应文字，供查看、继续聊天、检索和日记整理。语音合成只收到本次要说的话、指定音色和表达参数，不收到整段聊天历史、记忆文件或密钥以外的其他配置。

流程：用户消息 → 当前角色的上下文与DeepSeek → 保存回复文字 → 根据角色语音模式决定是否合成 → TTS → 校验并存入本地音频文件 → 同一条消息更新为可播放语音。聊天附件成功前不声称已经发送语音；不以“（发了一条语音）”文字代替真实文件。

本轮覆盖私聊、群聊的AI语音消息与主动消息的可选语音，分别使用角色自己的声音。用户录音识别与实时语音通话是后续独立扩展，不和第一版的TTS消息混成一件事。

## 服务选择

首个建议接入阿里云百炼CosyVoice-v3.5-flash，部署地域以华北2（北京）为初选，先小样试听后确定。备选为Qwen-Audio-TTS Plus等同平台模型。推荐仅基于能力、配置与计费方式，不宣称已经实测音质、延迟或动漫角色适配。

DeepSeek Key负责现有聊天，百炼Key负责语音。账号连接可以供两位角色共用，音色、语速、模式等角色配置分别保存。连接设置包括服务商、地域、业务空间ID和密钥；模型从实际可用列表或已核实配置选择。普通设置只显示音色友好名称，模型／音色ID放高级信息。

创建的音色绑定target_model；更换模型时必须重新验证或创建对应音色，不假设相同音色ID可跨模型使用。手机直接访问云端语音服务，不依赖家中电脑常开；这是个人自用App方案，若将来公开分发，应另行改为服务端签发短期凭证与限额控制。

## 音色来源与试听

三种来源：现成音色、文字设计音色、有权使用的录音复刻。推荐先做文字设计：每个角色生成三种候选，用相同的日常聊天、认真说明、安慰三类短文对比；选定后固定音色，不逐条重新设计。试听和正式合成的语音模型一致。

- 大肥鱼描述起点：年轻成年女性，普通话清楚，音色清亮有活力，轻微俏皮，表达自然，不夸张撒娇。
- 小白描述起点：年轻成年女性，音色柔和通透，语速略慢，表达温柔清晰，避免机械播音感。

上述是可调整的试听方向，不是用户已经确认的音色。可以重命名、试听、更换；改动影响新消息，旧音频保留原声。删除某角色的本地选择不自动删除云端音色；云端删除单独操作并提示可能影响其他引用。

复刻时按所选服务的真实要求验证，当前百炼相关模型建议10～20秒、最长60秒、文件不超过10MB、采样率至少16kHz，至少5秒连续清楚人声；不用歌曲、背景音乐、多个人声。上传前展示实际将上传的样本和用途。样本只在显式复刻操作中上传，不随普通聊天重复上传。

## 页面与默认值

入口：角色 → 对应角色 → 聊天设置 → 语音与音色。沿用已选淡紫卡片风格，输入一行一个，不让小白与大肥鱼出现两套布局。

页面包含：

1. 语音回复模式：关闭／文字加语音／语音优先（文字收起）／AI按需发送。默认关闭，用户选好声音再开启；已生成的语音仍可播放。
2. 当前音色：友好名称、来源、试听、更换；展开后有现成音色、文字设计、录音复刻。
3. 表达设置：语速、默认风格；音高、情绪等仅在实际模型支持时显示，不显示无效滑块。不以简单升降音高代替专属音色。
4. 发送规则：私聊／群聊、主动消息可否附语音、自动合成文本长度上限；默认自动合成短回复，长回复留文字并可手动完整转语音。
5. 播放设置：默认点按播放，自动播放独立开启；一个时间只播放一条，可停止、进度、倍速及查看文字，支持系统音频中断与耳机路由。
6. 服务连接及本机用量：连接测试、角色共用账号引用、请求数／合成量／估算费用、临时试听文件占用。

语速范围与风格支持由适配器约束。首版建议自动语音最多120个汉字的短回复，数值可调整；这不是时长保证。长文经用户选择可完整分段生成，不擅自截掉原话或加速。播放速度是本地播放器操作，不触发重新合成。

## 消息行为与AI权限

语音条显示角色头像、真实时长、播放状态和未听标记；可展开对应文字、长按重试或删除音频。未听状态不等于会话未读状态，打开会话不自动标成已听。群聊每条只由对应角色自己的音色合成，不串角色配置。

朗读使用可核对的口语文本，保留数字、条件和关键意思。Markdown展示符号和明确标为动作旁白的段落不机械朗读；不能粗暴删除所有括号内容。实际朗读文字作为语音的对应文字保存，避免语音说了一件事、展开文字却是另一件事。代码和长链接优先保留文字呈现。

自动播放仅限App前台且正在查看的会话，不在后台突然外放；播放由统一音频协调器管理，避免与已有闹钟试听抢占。用户已手动开始的播放与后台生成是两种能力，分别验证系统音频中断、恢复和静音策略。

AI按需模式复用工具机制，提供受控send_voice能力，只有对应角色开启后可用。一次回复最多一条主动语音，文本限长、音色来自保存配置；AI可以建议服务支持的情绪，不能更改用户音色、账号、付费额度或其他角色配置。用户明确要求语音时优先发送；不能成功时如实保留文字并提示。

文字加语音模式为同一消息提供两种呈现，不重复写两条历史；语音优先仍保留可查看文字。给后续模型、日记和记忆检索只提供一次文字内容，不因为附了音频再转写一次、重复增加上下文。

## 合成状态、重试与一致性

每条消息的语音状态独立保存为等待、合成中、就绪、失败或结果未确认。文字回复成功后即可展示，不被语音合成阻塞。

- 合成成功且音频校验、落盘完成才显示可播放；校验格式、实际时长、文件大小与摘要。
- 失败只重试本条TTS，不再次请求DeepSeek、不重发消息；同一请求同时只能执行一次。
- 请求前保存准备账本；重启遇到未确认结果不自动无限重试，提供手动操作。
- 网络中断不能保证服务端未计费；本地去重也不等于供应商计费幂等。不承诺所有失败调用免费。
- 重播已有文件不再访问TTS；主动重新生成或换音色重新合成可能收费，保留旧文件直到新文件成功。
- 合成结果发布前核对消息ID和文字版本；消息已删除、内容已变或任务已取消时，不把旧音频重新插回聊天。被取消的网络请求仍可能已在服务端产生费用。
- 去重键包括角色、原文、服务／模型／音色、表达参数与编码版本。更换配置只影响未来消息。
- 语音失败不悄悄换成另一种系统声音。可选系统朗读应另有明确入口和标识。

## 主动消息、通知与灵动岛

角色独立开关决定主动消息是否附语音，沿用已有允许时段及最短随机间隔，语音不另开一套排程。App有运行机会时提前准备文字与可选音频，消息到达时复用已准备文件。TTS失败保留文字投递，不为补语音在安静时段另发新提醒。

通知以提示音和文字告知有新消息；不自动播放完整聊天语音。灵动岛沿用人物头像和未读数，点击进入对应消息。临时签名不提供常驻后台能力；iOS不保证准点启动联网任务，因此当前条件不能承诺App退出很久后仍现场调用DeepSeek和TTS。

## 数据、本机文件和备份

音频存手机Application Support/Chat/Audio/<角色ID>/<资源ID>.m4a，优先M4A/AAC，兼容服务返回的格式后再编码。配置、文字和消息关系保存在本地数据中；模型与音色引用按角色隔离。密钥仍只在Keychain，不进Git、IPA或普通备份。音频不可写回只读App安装包。

正式语音附件是聊天数据，不作为可以随意清理的临时缓存。存储页区分正式消息音频、试听样本与临时文件；默认只提供清理试听／失败临时文件，删除正式附件必须明确选择。删除音频可保留文字，删除整条消息按现有规则处理。

现有备份是20MB上限的JSON，不能简单把音频Base64塞进去。新增带清单、独立音频和摘要的ZIP媒体备份，流式写入并显示导出大小；继续兼容旧v1/v2/v3。提供含音频完整备份和文字／记忆备份，后者明确标记不包含的音频，不假装能够离线回放。导入先验证、暂存，失败保留原数据。导出备份不等于复制供应商云端音色模型；换账号后自定义音色ID可能不可用，已保存本地语音仍可播放。

## 费用与限额

截至2026-10-31核对的百炼北京区原价：CosyVoice-v3.5-flash为0.8元／万字符，v3.5-plus为1.5元／万字符；Qwen-Audio-3.1-TTS-Plus为1.4元／万字符。Qwen-Audio-3.1-TTS-Flash按输入与输出Token计费，不能套用每万字价格。

示例：两角色合计每天40条、每条平均50个计费字符、30天，共6万字符；按上述CosyVoice Flash原价为4.8元／月。该估算不包含DeepSeek、试听重生成、复刻等额外项目，也不保证实际消费；服务商账单为准。

App记录合成请求、可核对的计费量和估算值，可设置每天自动合成字符上限，达到后继续文字聊天、暂停自动语音。限额按服务商计费单位处理，不把本地粗算冒充官方账单。播已落盘音频、查看文字、调播放器倍速不调用TTS。

## 实施与验收顺序

1. 配置与音色验证：接入一个服务，测试连接；分别为两个角色试听，确定模型与固定音色。
2. 消息与文件基础：真实语音附件、可播放条、文字对应、角色隔离、持久化、失败状态、重试去重和媒体备份兼容。
3. 交互能力：四种发送模式、群聊、AI按需工具、主动消息可选语音、用量限额与存储管理。
4. 验证交付：模拟服务逻辑回归、App／Widget编译和包检查；按用户既有要求不自行启动模拟器。真机测试两角色、群聊、重启、离线重播、耳机／来电中断、改音色后旧语音、导出恢复、失败只重试音频。真实接口音质和手机音频路由需要实际试听验收，不能用编译通过替代。

所需外部准备：开通百炼服务、地域和业务空间、可用Key；若选文字设计不需要录音，若选复刻需要合规样本。一次配置账号即可供两角色使用，音色分别设置；这份方案不要求自建常开服务器。

# mAIverse 下一轮改造清单

状态：用户已确认四个改动点并授权开始实施。本轮为 V1.2；当前正在实现与云端验证，实际结果见 docs/VALIDATION.md。

## 改动点 1：人物卡片、角色详情与图片放大

用户已同意以下方向：

- 角色列表使用专门的人物卡片，展示立绘、角色名字、来源和 Q 版缩略图。
- 点击卡片进入角色详情；“邀请上岛”与查看图片分开，避免查看图片时误切换角色。
- 详情页分别展示“日常小人物”和“展开立绘”，两种图片都能点开查看大图。
- 全屏看图支持双指缩放、双击放大和拖动，尤其解决当前岛上 Q 版图片不能放大查看的问题。
- 提供“日常 / 展开 / 锁屏”的效果预览，清楚区分原图查看与缩小后的岛上效果。
- 图片查看器可切换深色、浅色底色，便于查看白发、白裙和透明边缘。
- 页面以统一角色目录驱动，未来其他角色复用同一套卡片与详情页。

## 改动点 2：主 App 深色、浅色背景切换

用户要求当前黑色背景增加切换按钮，提供白色背景选项。

- 主 App 提供明显的深色 / 浅色切换入口，而不只是图片查看器的背景开关。
- 浅色模式使用白色或接近白色背景，深色模式保留当前深色方向。
- 文字、卡片、按钮、导航和详情页一起适配，确保浅色背景下仍有清楚的对比度。
- 保存用户选择，下次启动继续使用选定外观。
- 此项针对主 App；系统灵动岛和锁屏实时活动的外观单独按系统规则设计，不把 App 的白色背景直接套到灵动岛上。

## 改动点 3：Q 版人物在岛上活动

状态：用户已确认这是第三个改动点；先做实际灵动岛动作小样并真机验证，再决定完整动作方案。

用户希望日常岛上的 Q 版人物能走路、打滚、滚来滚去，有小伙伴自己活动的感觉。

- 动作方向先考虑走路、打滚，保留现有角色的白紫配色和身份。
- 目标场景是实际系统灵动岛；App 内的动作展示不能替代岛上的效果验证。
- 优先验证实际灵动岛的动画能力，再确定动作资源与实现方案。短时位移、翻滚转场和连续循环的技术要求不同，不能把前者说成后者已经实现。
- 苹果公开文档说明 Widget / Live Activity 动画单次最多两秒，可基于状态更新触发短动画；持续自主循环走路、滚动没有在本项目中验证，不能承诺后台每秒换帧或持续播放 GIF。
- 本项目前仅记录需求与技术边界，尚未制作动作素材、实施或真机验证。

参考：[Apple — Animating data updates in widgets and Live Activities](https://developer.apple.com/documentation/widgetkit/animating-data-updates-in-widgets-and-live-activities)。

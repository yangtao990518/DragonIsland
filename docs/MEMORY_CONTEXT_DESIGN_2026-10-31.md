# 角色聊天记忆与上下文：功能设计与页面原型

用户确认方向：原始聊天完整保留；每角色每天独立日记；上下文用自动摘要跨天接续，不增加话题／任务管理；长期事实／约定独立维护；按问题检索相关段落，不把全部日记塞进每次请求。原始消息、事实、角色感受和推测应区分；新约定应取代失效的旧约定。聊天请求可查看实际发送快照、选择来源和容量预算，不能把“已携带”说成模型必然采用。

本次仅为新功能页面原型，尚未实现日记归档、自动摘要、检索、向量索引、容量计量和请求快照；build20已有的手动记忆与待确认提取功能仍保留。后续新入口按用户要求放在：角色 → 对应角色 → 聊天设置 → 记忆与上下文。关于只保留数据占用与备份管理入口。小白、大肥鱼共用布局，数据隔离；群聊检索只包括角色参与且允许读取的内容。

## 三套静态原型

- A：淡紫简洁设置，依次显示下次携带内容、选择模式、容量、内容管理、每日整理。
- B：蓝白卡片，以输入＋回复预留预算和相关日记预览为主要信息。
- C：暖白日记，以每日独立文件列表为中心，话题／约定通过同级页签切换。

静态页面与PNG保存在本机项目output/ui-memory-concepts-2026-10-31/，不属于正式App资源。图中数量、日期条目、检索结果、容量均为示例。12K输入＋4K回复预留＝16K／32K预算，模型容量与会话预算分开。原型中的1M模型容量为当前示例，正式功能应读取实际模型元数据；发送前估算与接口返回的实际用量分别标识。整理时间不代表iOS保证准点联网，界面注明到点待整理、打开时补齐。

imagegen三次请求均返回usage_limit_reached（429），没有成功生图。此次展示改为本地HTML/CSS布局渲染PNG，不是imagegen图片，也不是App运行截图；未调用付费API生图备用方式。使用项目现有正常版大肥鱼头像，未生成或改动人物动作素材。未启动模拟器。

## 主动聊天保存问题

用户截图显示群聊目的地被选中，保存报笼统的时段／次数／群聊错误。弹窗挡住实际群聊选择，不能仅凭截图认定手机端究竟是哪项失败。已查明代码会把未选群聊、失效群聊、时间相同等情况统一报成同一句，且分段选择群聊后仍需另选具体群，界面未充分提示。

本次修复：
- 目标群聊改为明确的可点击选择行；切到群聊且目标未选时，弹出有效群聊列表。
- 显示选中群名与“将在此群@你”；没有群聊或尚未选目标时给出就地提示。
- 共享模型与App保存预检使用明确的时间、最短间隔、缺少群聊和群聊失效错误。保存失败保留原设置，不擅自改为私聊或发送到另一个群。
- 添加有效群＋15分钟间隔保存／重启、缺少群聊不改原设置、删除群后重新选择、不同错误与关闭开关等回归。

这些修复是build20之后的源码改动，尚未生成新的IPA。云端逻辑与语法验证结果待补充；不称已在真机重现或修复验收。

## 三项功能范围与早期A原型

用户确认主页面采用A淡紫简洁设置风格，随后明确“进行中的话题没用，不在范围内”。因此取消独立话题／任务管理，不增加话题列表、项目进度、待办、完成状态与话题维护入口。较早的四项原型仅为历史方案，不能据此恢复已取消功能。聊天连续性仍由最近对话与后台自动摘要处理，摘要作为上下文来源可查看，不设计为用户维护的任务系统。

现行主页面内容管理仅有三项，子页面共三组、六个静态页面，左列表右详情或编辑：

- 每日日记：按日独立文件、大小、检索状态；详情分为当天事情、确定事项、还想聊的事、角色随笔、来源与使用。角色感受不写成用户事实。
- 事实与约定：文件大小、始终携带／按需检索／停用、当前有效版本；编辑页输入一行一个，带原话与历史版本入口。
- 待确认记忆：新记忆与约定更新分组、来源核对；详情对比旧约定与建议内容，确认后更新并保留旧版历史。

最新主页面和子页面评审图片、可复现布局源文件存于docs/design/memory-context-a-subpages/。被取消的话题预览保留在本机output的superseded-topics目录，未删除历史预览，也不加入现行评审包。页面数值与内容都是示例；旧约定09:00–18:00仅用于展示冲突更新，不代表用户真实配置。记忆里的联系时间仅影响聊天资料，不直接修改App主动聊天排程，界面已注明。

本轮使用HTML/CSS布局渲染，未调用imagegen或付费API，没有修改App功能源码、没有启动模拟器或生成IPA。日记／检索／自动摘要等尚未实现，本文记录的是设计范围。

## UI第二轮：原生风方向，尚未选定

用户看过早期A子页面后认为界面偏丑、不如原生，要求重新提供几套，因此A不再视为已确认的最终视觉。三项功能范围保持不变：每日日记、事实与约定、待确认记忆；不恢复话题／任务管理。

本轮提供三套同功能布局对比，每套从左到右为主设置、日记列表、记忆编辑：

- 原生设置版：系统式浅灰分组背景、蓝色操作、绿色开关、正常导航栏、右上角保存。
- 阅读列表版：暖白底色、平面分隔线、文字优先、少量暖色操作。
- 轻量伴侣版：白色背景、少量淡紫点缀、紧凑列表。

移除重复的大人物标题、装饰卡片、底部大按钮和大块说明。输入字段仍一行一个，原话和大小通过普通行展示。文件存于docs/design/memory-native-v2/，旧版预览保留。内容与容量均为示例；此轮仍为HTML/CSS渲染原型，非App运行截图，没有修改App源码或生成IPA。

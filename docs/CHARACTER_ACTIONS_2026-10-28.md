# 角色日常动作与视频对比

## 行为变更

- 将日常动作入口从「我的世界」移到「角色 → 角色详情 → 日常动作」。在未选择为当前陪伴的角色详情中，也会编辑该角色自己的动作。
- 每个角色单独保存自动活动、走路、打滚及专属动作开关。小白可单独启停御剑；大肥鱼可单独启停骑鲸、遛狗。关闭走路不再关闭专属日常；全部关闭时只待机。自动活动关闭时静态展示。
- 旧全局设置作为每个角色初始值迁移：原来关闭走路时，专属移动动作默认也关闭，保留此前选择；之后角色设置互不覆盖。修改正在陪伴的角色立即更新实时活动，编辑其他角色不改变当前陪伴。
- 角色页增加横向卡片/纵向列表切换，记住浏览方式。横向卡片下方用正常人物头像快速切换当前查看卡片；浏览其他角色不强行切换正在进行的陪伴。

## 遛狗(视频测试版)

仅在大肥鱼的日常动作页面提供，使用 AVQueuePlayer / AVPlayerLooper 解码真实 H.264 MP4。与抽帧版使用同一份用户确认的去绿边 v4 图集、60 FPS 时间轴、20 秒完整往返、相同尺寸及黑色舞台。此版本比较的是图片序列和视频解码播放路径，未重新生成动作；并非未经处理的原绿幕视频，也没有视频透明通道。视频约 3.3 MB，仅放入 App 资源，不加入 Widget。

「视频测试版」是 App 内对比预览，不加入岛上的自动动作开关。灵动岛继续使用系统计时字体方案，不能以 App 内视频播放验证灵动岛也支持该播放器。离开页面或 App 不活跃时暂停；启用减弱动态效果时由用户点播放。

重建视频：`python Scripts/prepare_dog_walk_video.py --ffmpeg <ffmpeg路径>`。日常构建直接使用已提交的 MP4，无需额外安装 ffmpeg。

## 动作资源

原八组自动计划无法表达独立专属动作开关。生成器现使用走路=1、打滚=2、御剑/骑鲸=4、遛狗=8 的位掩码，小白生成 16 个计划、大肥鱼生成 32 个计划；仍为 361 个系统字体文件。每个计划 60 秒，保留完整往返和原动作时序。一次循环按可用时长安排已开启动作，计划变体让多项动作都有机会出现。待机、转向及所有移动画幅检查继续保留。

源码预留下一包版本为 V1.8 build 16。未改动安装助手、签名缓存和已交付的 V1.8 build 15 IPA。本轮源码完成后需重新构建安装包才能在手机看到这些改动。

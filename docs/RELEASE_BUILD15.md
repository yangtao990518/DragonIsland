- 取消小白遛龙，不加入本版。
- 接入已确认的小白御剑、大肥鱼骑鲸（眨眼 revision3）及大肥鱼遛狗（AI 视频提帧抠像 v4）。

## 正式素材与清理

正式动作源：`Art/DailyMotions/manifest.json` 和三组无损 WebP 图集，约 10.05 MB。图集是构建输入，编译时生成 iOS 使用的 PNG 图片及字体，App 不直接解码 WebP。导入时固定整段画布缩放，未逐帧重新居中、生成新姿势或改变眨眼时序。

用户明确批准具体清单后，删除 3414 个旧文件，约 3.396 GB；其中 Git 已跟踪旧文件约 700.76 MB。范围包括 `AnimationDrafts/` 旧恢复压缩包、失败走路试稿及相关脚本、旧动作源大图、重复预览、已取消的小白遛龙首帧、v1-v3 抠像试稿及缓存。构建所需原画、声音、基础动作 PNG 和全部文本记录保留。大肥鱼 v4 的透明主帧和一份最新预览本地保留。

清理只作用当前分支和本机项目文件，不重写 Git 历史。原有历史提交中的大文件仍可恢复，因此 Git 全历史仓库的体积不会随本次提交立即缩小。

旧交接记录中的试稿和恢复 ZIP 链接是历史记录，文件已按此次授权删除；后续以本文件与 `Art/DailyMotions/` 为准，不再运行旧恢复脚本。

## 验证范围

提交前通过 Python 检查，包括角色/声音资源、打包结构测试、动作开关、八组计划闭环、方向镜像、原眨眼时长、全程边界与位置连续性，以及 60 FPS 预览逐帧顺序。已实际编译并核对 361 个不透明动作字体资源。

Windows 本机不能执行 Xcode 编译。提交后由 `Package current unsigned IPA` 工作流执行 Swift 测试、Python 回归、资源生成、CoreText 字体校验及真机架构 App/Widget 编译，成功后上传未签名 IPA。本工作流不等同于模拟器或真机连续播放验收；安装时继续使用本机安装助手，并保留 Widget 扩展。

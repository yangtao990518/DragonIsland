# mAIverse V1.8 build 22 — PixelFX 全库

- 游戏技能改用 PixelFX，全库244项、21类均可搜索、预览和选择为初始技能；升级时也可打开完整技能库选择。
- 每局最多装备6项技能，每项最高5级，全部自动施放。根据效果类型采用弹体、范围、护身、治疗、环绕五类战斗规则；不把244个演示当作244套已经逐个手工还原的独立战斗机制。

- 修复初始暂停/升级状态恢复渲染，统一角色待机与跑步显示比例。支持本机存档、暂停和续玩。

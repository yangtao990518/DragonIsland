# mAIverse V1.4 改动清单

内部版本 1.4（build 7），主 App 和 Widget 同步。本机交付目录为 `D:\gpt_workspace\ios_ldd\mAIverse-V1.4\`，保留旧版本目录。

## 这次接入

- **新 Q 版**：首页头像、角色卡片、详情大图、日常 / 最小态灵动岛使用新造型；小握拳、两只白角。旧原图保留，成年展开立绘保留。详情使用高分辨率新母图。
- **动作素材进入安装包**：待机、右走、左走、打滚、转身共 36 个帧文件，包含共用端点。步行有抬腿、重心变化，打滚有蹲下、蜷身、倒转和起身。保留提示词与来源。
- **新增任务页**：预览动作、开关自动活动、勾选走路 / 打滚。未选动作不会进入计划，都不选时待机，关闭自动活动则静态。选择保存并应用当前陪伴。
- **自动播放**：开始陪伴后离开 App，五秒一个时段，做完动作后待机；移除旧手动测试按钮及短暂后台测试任务。
- **动作衔接**：步行含起止姿势，左走含转身，打滚首尾回到共同中立。位移编入帧，不靠后台循环更新活动。
- **本地播放器**：系统计时文字、彩色帧字体和遮罩驱动；主 App 预览读取同一计划。没有新增网络、账号、推送或 App Groups 权限。
- **资源去重**：字体内重复帧使用引用，单个 bundle 的字体资源从约 139MB 降到约 16.5MB。
- **看图退出修复一起交付**：单击返回，未缩放时下滑关闭，双击仍可缩放，放大后拖动不误关闭，保留 X。

## 实现边界

- 每套预排计划为 60 秒循环，开局从两套种子中选择；不是后台每五秒重新抽签。未来增加动作需补素材和计划编译资源。
- 息屏低亮度、减弱动态效果主动静态，系统也可能限帧。用户 iOS 27.01 的长时间后台表现仍需实机确认。
- AI 绘制的发梢 / 衣纹有轻微变化，不声称电影级动作或 60fps。
- 升级后结束旧活动再开始，加载新计划。到期仍不保证精确收起或响铃。
- 实际构建、测试和校验值见 `VALIDATION.md`，本文件不单独证明测试成功。

# mAIverse V1.5 改动清单

内部 1.5 / build 8；本机目录 `D:\gpt_workspace\ios_ldd\mAIverse-V1.5\`，旧版本保留。

- 修复动作叠影：V1.4 将透明帧直接用于累积叠放，旧姿势从新帧透明区域透出。本版仅在灵动岛字形内预合成完整不透明黑色底面，每次覆盖旧人物；App 资源仍透明。
- 岛上播放目标从 8fps 提高为 30fps，所有计时层、字形阶段、计划采样和 App 内预览一致调整。不是将八帧简单重复标成 30fps；左右走路各替换为 16 个绘制姿势，走路循环约 0.53 秒。
- 打滚也由 8 帧扩充到 16 个帧文件（包含共用中立首尾），补蹲下、蜷身、倒转、落地与起身；每个动作时段连续滚两次，再回待机。
- 修正左走转身、迈腿和收脚时序：仅在步态有效区间移动，转身 / 收脚阶段停止位移；右走也使用相同的有效步态区间。
- 步行位移从 ±10 增至 ±16，移动阶段从 1.5 秒缩至约 1.07 秒，相同岛上尺寸的横移速度约为旧版 2.25 倍。
- 30fps 使用 60 个阶段层，共享一份可变动作字体及一份遮罩字体；动作集合 / 阶段通过字体轴选择，跨全部集合去重。字形按 32pt@3x 的 96 像素生成，避免注册数百个字体。每套仍为 60 秒循环、五秒一个时段，支持原动作筛选和关闭自动活动。
- 增加针对旧帧透出、30fps 相位顺序、移动区间与脚步一致的回归检查；云端增加实际 SpringBoard 视频与视频帧分析，便于检查屏幕中的叠影和节奏。

30fps 是播放目标，系统可能降帧；视频中姿势保持、压缩误差与采样时钟都不能用来声称真机锁定 30fps。减弱动态效果 / 息屏低亮度仍静态。到期仍不保证准点收起或响铃，未新增 AI 对话、推送或后台 Timer。

安装后先结束旧活动，再开始新一轮。Sideloadly 必须同时保留并签名 Widget 扩展。实际构建、测试与交付校验见 VALIDATION.md；没有替用户签名或实际操作其手机。

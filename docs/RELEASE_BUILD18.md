# mAIverse V1.8 build 18

- 小白、大肥鱼各新增 20 张内置静态 Q 版透明表情，包含抽象、搞笑、认真与常用情绪。保留生成原图，App 打包为适合聊天显示的透明副本；用户可直接选用，AI 在该角色「允许 AI 发送专属表情」开启后可选用。自定义表情仍单独管理，内置表情不占自定义名额。
- 新增「聊天 → 左上角聊天设置 → 主动聊天」：默认关闭，默认只在手机本地时间 10:00–18:00 随机联系，支持自行修改允许时段、每角色次数与私聊／指定群聊 @。关闭或改变设置会取消旧的待发安排。
- 当前为手机本地预生成方案：App 可运行时用真实接口提前准备下一时段的消息，系统通知按计划时间投递，重启不重复生成或重复写入。没有准备好的消息就不会发送，缺密钥／网络失败不伪装成成功，不会把准备指令保存为用户发言。
- 提醒带有未读计数及会话跳转；App 获得运行机会时更新独立的聊天灵动岛，读取后移除提醒，不改写原陪伴计时。**临时签名和当前无在线服务的条件下，不能保证关闭 App 很久后持续生成消息，也不能保证后台到点刷新灵动岛**；后台已准备消息使用系统通知。全天候微信式即时生成与灵动岛推送尚未接通。
- 修复进入单聊／群聊时默认定位最新消息。移除旧「遛狗视频测试版」入口、播放器和测试 MP4；正式遛狗 96 帧／1.6 秒、御剑／骑鲸与两段完整舞蹈保持不变。
- AI 人格设置页面暂不改版。此前角色详情和日常动作的新外观仍是设计原型，未包含在本包中，避免将原型图当成已实现界面。

本包沿用 App／Widget 标识。通过 Sideloadly 使用原 Apple ID／签名身份覆盖安装，安装前建议导出聊天备份；请勿先卸载旧 App。当前 IPA 未签名，安装时应保留 Widget 扩展。不要将私密签名缓存上传或跨电脑直接套用。

云端与本机验证的实际结果在本轮交接记录补充；生成 IPA 不代表真机安装、系统通知时机或长期后台体验已经验收。

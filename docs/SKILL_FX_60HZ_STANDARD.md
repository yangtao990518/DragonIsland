# 技能特效 60 Hz 制作标准（2026-11-03）

用户明确要求：技能特效统一采用 60 Hz；选择重新生成更多逐帧原画，不使用运动补帧。

- 时间轴每秒 60 个显示采样；原有动作总时长、命中点、冷却和等级规则保持。末帧可保留不足 1/60 秒的原始尾时长，不加速旧图集来凑 60 FPS。
- 每个动态阶段生成连续原画，保持同一主体、材质、固定画布与公共锚点。不得把重复帧、网页刷新率、光流补帧或混合淡化标成 60 帧原画。
- 允许有意的静止停顿，但必须在时序中说明；不能用长时间重复帧冒充新增动作。
- 原始生成图、提示词、帧索引、显示时长、来源哈希和处理规则分别保存。旧确认稿保留，新版通过审阅后才替换。
- 图集只做去背景、拆帧、公共缩放和导出；不逐帧按外接框缩放/居中，不以程序几何绘制替代技能原画。
- 检查全部帧的裁边、空帧、连续性、尺寸漂移、背景污染、循环接缝及命中时刻。60 Hz 不自动保证动作自然，必须同时审阅原速和慢放。
- 当前范围为火球、雷电、环绕剑、追踪剑及新增四项土系的技能特效。追踪剑按用户后续截图恢复制作：细小青白剑群从身上飞出，自动寻敌，最多50把；各等级共用同样的小剑尺寸、单把伤害、速度、冷却、颜色与命中特效，唯一升级区别是数量（预览暂设10/20/30/40/50）。不再合成大剑。角色、怪物身体动画和已确认视频不因本规则重新生成或改变时序。
- 原画资源达到 60 Hz 与设备实际呈现频率分开报告；原生游戏尚未接入的新素材不能宣称已在 App 上达到 60 FPS。

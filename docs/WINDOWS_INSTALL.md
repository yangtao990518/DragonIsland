# mAIverse：Windows 安装与排错

## 你下载到的是什么

GitHub Actions 的构建产物带版本号，例如 `mAIverse-V1.4-unsigned`。解压下载的 ZIP 后使用里面的 `mAIverse-V1.4-unsigned.ipa`，不要把外层 ZIP 直接交给签名工具。后续版本使用对应版本号的文件；桌面名称始终为 mAIverse，内部 App 与扩展文件名仍沿用下面的路径。

IPA 内应有：

- `Payload/DragonIsland.app/`
- `Payload/DragonIsland.app/PlugIns/DragonIslandWidget.appex/`

云端脚本会检查这两者及其资源，但无法验证你的实际签名和真机显示结果。

## 用你已有的签名方式安装

你已经安装过 D2R Mobile，可以继续使用熟悉的签名工具；本工程额外需要它支持 **App 扩展**。

若使用 [Sideloadly 官方 Windows 版](https://sideloadly.io/)：

1. 用 USB 连接 iPhone，解锁并信任电脑；按 Sideloadly 当前文档准备驱动等依赖。
2. 拖入本项目 IPA，选择你的设备，使用你自己的 Apple 账号签名。
3. 检查高级设置，**不要移除 App Extensions / PlugIns**；需要同时签名主 App 与 `DragonIslandWidget.appex`。
4. 若工具更改了主 App 的 Bundle ID，扩展 ID 也必须相应修改并保持主 ID 的前缀。让支持扩展的签名工具处理，不要只手改一个 ID。
5. 按 iOS 提示信任开发者、必要时启用开发者模式。
6. 首次打开主 App，选择 1 分钟并开始，再回到桌面查看。

账号与密码只在你自己的工具中输入，不需要写进 GitHub 或发送给他人。免费账号通常需要每 7 天续签，并有 App 数量和 App ID 配额限制；扩展也会消耗相关配额。云端编译成功不代表任意签名工具/账号组合都一定能装好。本工程没有进行实际签名测试。

## App 打开了但没有灵动岛

依次检查：

1. 手机是否真的配备灵动岛。没有的设备请先看锁屏卡片。
2. 是否在 App 内点击“开始陪伴”，并成功创建了实时活动。
3. 设置中是否允许该 App 的实时活动；其他活动或系统状态也会影响展示。
4. 签名时是否删除了 Widget 扩展。最常见的情况就是主 App 留着，`PlugIns` 被删了。
5. 扩展是否和主程序都签好、包名匹配。只把本 App 放进另一个 App 的容器，不等同于正常安装并注册 Widget 扩展；第一轮请正常侧载安装。
6. 开始后先回桌面，长按灵动岛看展开视图。无须到桌面小组件库“添加小组件”，本项目只包含实时活动。

## 倒计时到零还在

这是第一版的已知边界：系统倒计时会停止，但 App 在后台没有永久运行的计时器，也没有服务器推送精确结束。请点“结束”，或者回主 App 收起/重新开始。没有自动响铃。

## 需要反馈时提供什么

- iPhone 型号、iOS 版本。
- 使用的签名工具、是否保留扩展、免费或付费账号（不要提供账号密码）。
- App 内提示原文、能否看到锁屏卡片、能否看到灵动岛。
- 若云端构建失败，提供错误行或 `mAIverse-build-log`。

修改后沿用同一签名身份与包名覆盖安装；升级前若担心丢失当前状态，先结束本轮。此原型未保存历史会话。

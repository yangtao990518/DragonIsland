# mAIverse V1.5 安装后验证

安装包内部为 1.5（build 9）。用 Sideloadly 覆盖安装，保留并签名 `PlugIns/DragonIslandWidget.appex`。升级前先结束旧活动，重新开始一轮加载新版帧和 30fps 计划。

1. 点首页或角色页右上角太阳 / 月亮按钮，切换深色与白色背景。关闭再打开 App，检查选择是否保留。
2. 进入角色页，点小白卡片进入详情，分别打开“展开立绘”和“岛上小人物”。检查双指缩放、双击放大 / 还原、拖动、“还原”按钮及看图背景切换。V1.3 支持单击图片返回详情，未缩放时也能单指下滑关闭；放大后的下滑仍用于查看图片，不会直接退出，双击也不应误触单击退出。
3. 角色详情可预览日常、展开、锁屏三种形态；“邀请上岛”与看图是不同操作，不会在看图片时误切换角色。
4. 默认桌面图标为用户提供的 GPT 款，可在“关于 → 桌面图标”选择其他四款。系统可能显示图标更换提示；更换图标不会切换角色。
5. 进入“任务”，预览新 Q 版待机、右走、左走、打滚。开启自动活动，勾选走路和打滚。用 1 分钟开始陪伴后直接返回桌面，无需点动作测试按钮；再用 25 分钟观察至少五分钟，并检查切换其他 App、锁屏 / 解锁后是否继续。
6. 只勾选走路时不应打滚，只勾选打滚时不应走路；两者都不勾选时只待机，关闭自动活动时静态。退出重开后选择应保存。长按灵动岛展开，点招呼 / 心情检查短句更新；展开态名称旁也使用新小人物。
7. 检查展开态三个按钮是否完整，锁屏是否使用大立绘。陪伴进行中退出再打开 App，检查状态恢复；点“结束”后检查岛上与锁屏活动均消失，再开始新一轮确认没有重复活动。

自动动作采用预先编排的随机片段，五秒一个时段，短动作结束后接待机。本版每套计划为 60 秒并循环，开局从两套种子中选择；不是后台每五秒重新抽签。使用系统计时字形 / 遮罩驱动，无后台常驻 Timer、服务器或推送。减弱动态效果、息屏低亮度时静态；系统可能限帧，模拟器不代替 iOS 27.01 实机验证。

V1.5 重点：只勾选走路，录下左右来回；确认移动时只有一个完整人物，没有旧腿、旧尾巴或旧身体透出。确认左走转身时停止横移，迈腿时再移动；比较 V1.4 横移速度和步频。本版目标 30fps，真机可能因系统调度而降帧，不保证锁定 30fps。普通紧凑态播放动作；同时存在其他活动时的最小态小圆标，以及展开态名称旁小图使用静态 Q 版，展开大立绘保留。

请反馈：离开 App 后能否看见迈腿和蜷身翻滚、几分钟后是否还在动、筛选是否有效，以及展开按钮是否完整。到期仍不保证到秒收起或响铃，必要时手动结束。

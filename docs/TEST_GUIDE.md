# mAIverse V1.6 安装后验证

内部版本 1.6（build 12）。Sideloadly 保留并签名 PlugIns/DragonIslandWidget.appex；升级后先结束旧活动，再开始新一轮。

1. 在“关于 → 岛上小世界”选择经典黑色、小小草地、月下星夜。退出重开应保留选择。已有陪伴时直接切换，回桌面检查场景已变、人物仍在，倒计时没有重新开始。
2. 场景出现在 App 内容区域：紧凑态人物活动区与倒计时区、展开内容和锁屏卡片。系统黑色外壳和摄像头区域仍黑，不能跨摄像头绘制人物。
3. 任务页只勾走路，开始 25 分钟陪伴并返回桌面。看人物缓慢迈腿，在左侧活动区走到另一端，停步转向，再折返回来。一趟约 5 秒、往返约 10 秒；行程较 V1.5 明显拉长，而不是加快脚步。检查两端角、脚、翅膀和尾巴完整，没有旧身体透出或站姿闪回。
4. 只勾打滚时，约一秒滚一次后待机，不再短时间连滚两次。都不勾选仅待机，关闭自动活动静态；选择退出重开保留。
5. 长按展开，确认大立绘与招呼 / 心情 / 结束按钮完整、文字清楚；点招呼和心情更新短句。重开 App 恢复当前活动；结束后岛上与锁屏活动都移除。
6. App 深色 / 白色外观、角色卡片、两种大图的双指 / 双击缩放、拖动 / 还原、单击或未缩放下拉关闭，以及五款图标继续验证。
7. 在手机上观察至少五至十分钟，再切其他 App、锁屏 / 解锁。减弱动态或息屏低亮度使用静态人物。30fps 是目标，不承诺真机锁定帧率或耗电水平。

自动动作是预先安排的 60 秒循环，开局从两套种子选择；走路为相邻去程 / 回程两段，其后继续选择随机片段。没有后台常驻 Timer、每帧 Activity.update、服务器或推送。到期仍不保证准点收起或响铃，必要时手动结束。

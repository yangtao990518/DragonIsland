# mAIverse V1.3 安装后验证

用 Sideloadly 覆盖安装本版本时，保留并签名 Widget 扩展。主 App 和扩展包名沿用旧版本，内部版本是 1.3（build 6）。

1. 点首页或角色页右上角太阳 / 月亮按钮，切换深色与白色背景。关闭再打开 App，检查选择是否保留。
2. 进入角色页，点小白卡片进入详情，分别打开“展开立绘”和“岛上小人物”。检查双指缩放、双击放大 / 还原、拖动、“还原”按钮及看图背景切换。V1.3 支持单击图片返回详情，未缩放时也能单指下滑关闭；放大后的下滑仍用于查看图片，不会直接退出，双击也不应误触单击退出。
3. 角色详情可预览日常、展开、锁屏三种形态；“邀请上岛”与看图是不同操作，不会在看图片时误切换角色。
4. 默认桌面图标为用户提供的 GPT 款，可在“关于 → 桌面图标”选择其他四款。系统可能显示图标更换提示；更换图标不会切换角色。
5. 选 1 分钟开始陪伴，在正在陪伴卡片中找到“岛上动作小样”。点“测试走动”后 5 秒内返回桌面，观察 Q 版人物是否出现一次短位移。再测试“翻滚”。可另开一轮避免计时到期。
6. 长按灵动岛展开，点“招呼”触发走动状态，点“心情”触发翻滚状态。展开态名称旁也放了小人物，以便直接观察状态更新的过渡。
7. 检查展开态三个按钮是否完整，锁屏是否使用大立绘。陪伴进行中退出再打开 App，检查状态恢复；点“结束”后检查岛上与锁屏活动均消失，再开始新一轮确认没有重复活动。

动作入口是可行性小样：当前使用单张角色图片的位移 / 旋转过渡，不是逐帧走路素材，也未实现持续自主循环。系统可能省略动画，减弱动态效果与息屏显示时不强制播放。5 秒测试只申请一次短暂后台执行时间，不维持后台常驻。

请反馈：测试入口是否成功、是否能看见短动作，以及展开按钮是否完整可见。App 内预览或模拟器截图不能代替你手机上的灵动岛动画验证。

# A / B 按钮素材生成说明

生成方式：内置 imagegen，透明背景，非 CLI。输入是用户确认的 A/B/C 对比图（只采用 A、B）和仓库 `Art/dafeiyu-chibi.png`。`source-sheet.png` 是工具原始输出；六张独立按钮由 `Scripts/prepare_home_buttons.py` 固定裁剪、等比缩放并放入透明画布，不生成新动作，不对动画原帧做修改。底部文字由 App 覆盖。

最终生成提示词：

> Produce a production UI asset sprite sheet containing exactly SIX isolated opaque anime-game illustrated buttons on a truly TRANSPARENT background. Use a precise TWO COLUMNS by THREE ROWS equal-cell grid, all 6 assets centered in their cells, consistent size and alignment, no touching, no shadows beyond the cell. Reference image 1: faithfully preserve the approved A style in the LEFT column (navy and warm gold enamel RPG shield badges with cream bottom label plaque), and the approved B style in the RIGHT column (turquoise / peach / lavender soft candy rounded-square badges with cream bottom label plaque). Do NOT include the C pixel style. Reference image 2 is the actual character to use INSIDE action and preview badges: the BLUE-haired whale maid with blue eyes, white maid headband and blue bows, navy maid outfit. Do not use the white-haired cat girl from reference 1, do not add cat ears or paws. Top row action badges: adorable blue-haired whale-maid head and shoulders, happily waving, with a small lively motion accent. Middle row scene badges: the beautiful small open window with sky, sea/grass and flowers matching reference 1. Bottom row preview badges: a little horizontal smartphone / Dynamic Island showing the same blue-haired whale-maid portrait, matching reference 1. Each badge includes a spacious BLANK cream bottom nameplate for native app text. Absolutely NO LETTERS, NO Chinese characters, NO A/B headings, NO text anywhere. Bottom plaque occupies the same lower region in every cell. Keep every badge's full outer silhouette and gold edges visible, opaque colorful interiors, finely illustrated, polished anime game quality. All six must have consistent overall dimensions and comparable label-plaque placement. Large even transparent gutters; each button centered, fills about 80% of a square grid cell. Orthographic flat 2D UI assets, not a tilted sheet or a mockup, no background scene, no checkerboard baked into pixels.

工具实际输出为 1536×1024，六块的精确裁剪区域及源文件 SHA256 记录在 `manifest.json`。不能假设输出严格等分；重新生成时须重新核对区域，不能直接复用本次裁剪参数。

# 完整视频动作基础素材

本目录保存两段大肥鱼舞蹈的完整原帧版。每段 720 帧，1280×720 原始画布，播放时长 12.096009 秒。原片 MP4 原样保留；舞蹈动作、表情、服装、头发、尾巴均来自原片，没有生成新姿势或清晰度再生。高清修复版应另建动作和目录，不覆盖这里。

`manifest.json` 索引各段 manifest。每段包含原始 PTS、时间基、真实逐帧停留时间、末帧停留、固定整段裁剪范围、原片 SHA256 和每帧完整 RGBA 像素 SHA256。图集为 3×4 格无损 WebP，各 60 页。解码、补回固定透明画布后可逐帧校验。

常规构建运行 `Scripts/prepare_assets.py` 和 `Scripts/prepare_motion.py`，无需重新抠像。它们生成 App 显示副本以及灵动岛字体帧资源；原始源图集保持原分辨率。大肥鱼已有遛狗 v4 位于 `Art/DailyMotions/`，不在这里重做。

新视频处理前必须阅读 `docs/VIDEO_FRAME_EXTRACTION_RULES.md`，不得复用本次其他动作的例外帧范围。处理过程和本机依赖见 `docs/HANDOFF_2026-10-29.md`。
